# 引擎对比：为什么默认换成 SenseVoice

2026-11-20 ｜ 真实气声基线（`bench/` 50 句，其中 001/002 是静音）

## 结论

**默认引擎从 faster-whisper small 换成 SenseVoiceSmall（sherpa-onnx）：**

| 引擎 | 总体 CER | 有效 48 句 CER | 单句耗时 | RTF |
|---|---|---|---|---|
| whisper `small` | 70.8% | 69.6% | 2.7s | 1.46 |
| whisper `medium` | — | 51.3%（20 句子集） | 12.4s | ~4.6 |
| **SenseVoiceSmall** | **50.1%** | **48.0%** | **0.05s** | **0.04** |

等于**同时**拿了 20 个百分点的准确率和 50 倍的速度。whisper 保留为可选引擎（`engine=whisper`），
用来做对照或换更大的模型。

## 其他数据

| 数据 | whisper small | SenseVoice | 说明 |
|---|---|---|---|
| `bench`（气声，50） | 70.8% | **50.1%** | 主基线 |
| `bench-close`（近讲，10） | 56.9% | **36.5%** | 近讲录音同样更好 |
| `bench-normal`（正常音量，1） | 66.7% | 93.3% | **只有 1 句，不足以下结论** |
| `bench-synth`（合成气声，50） | 18.2% | **11.5%** | 合成集同样更好 |

分类（SenseVoice，气声）：日常 41.6% / DSH 47.0% / 人名地名 50.0% / 数字标点 65.6%。

## ITN（数字转阿拉伯）的坑

SenseVoice 默认 ITN=on（数字输出 `2026`、`12.5`），但评测语料的人名/数字句参考文本用的是
中文写法（`二零二六`、`十二块五`），所以 CER 被「写法不同」放大：

| 配置 | 总体 CER | 数字标点分类 |
|---|---|---|
| ITN on（默认） | 50.1% | 65.6% |
| ITN off（`--no-itn`） | **47.4%** | 53.2% |

**这不是识别变准了，是归一化口径不同。** 日常输入里数字写成 `8点`、`12.5` 更好用，所以默认保持
ITN on；做评测时想排除写法影响就加 `--no-itn`。

## 试过但没用的（负面结果，省得再试）

| 手段 | 结果 |
|---|---|
| 谱减降噪 | 48.0% → 47.9%（无变化） |
| 低频补偿 +6/+9dB | 48.0% → 47.7/47.6%（噪声级，且 whisper 上也只有 1.7pt） |
| 动态压缩 | 48.0% → 49.1%（更差） |
| VAD 裁剪参数（不裁 / pad 0.3 / margin 4dB / 18dB） | 48.0 / 48.3 / 48.2 / 53.3% |
| LLM 纠错（DeepSeek，只给文本） | 48.0% → 47.0%（3 句变好、2 句变坏，且 +1.4s/句） |

结论：**瓶颈是真人气声本身的信息损失（辅音弱、无基频、口型不确定）和采集链路，不是后处理。**
再往下要动模型（微调）或采集质量，不是调预处理。

## 怎么切

```bash
python -m whispertype config set engine sensevoice   # 默认
python -m whispertype config set engine whisper      # 切回 whisper
python -m whispertype config                     # 看当前配置（含 engine / itn）
```

DSH 插件不用改：它拉起的是 `python -m whispertype.server`，服务读同一份配置；
`GET /health` 里会显示 `engine`。改完重启服务（或重启 DSH）生效。

## 复现

```bash
cd whisper-type
python tools/benchmark.py                          # 默认 sensevoice
python tools/benchmark.py --engine whisper         # whisper small
python tools/benchmark.py --engine sensevoice --no-itn
python tools/exp_trim.py                           # VAD 裁剪实验
python tools/exp_llm_fix.py                        # LLM 纠错实验
```

报告在 `docs/bench_report*.md`，汇总表用 `python tools/compare_modes.py`。
